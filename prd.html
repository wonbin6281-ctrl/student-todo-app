Product Requirements Document

능동 밥집 추천 AI

광진구 능동 자취생을 위한 AI 기반 식사 메뉴 추천 웹앱

버전 v1.0
작성일 2026-06-09
형태 HTML 단일 파일
위치 광진구 능동
1

개요

목적 광진구 능동 자취생이 매일 "뭐 먹지?" 고민을 AI와 대화하며 해결
핵심 가치 최근 3일 식사 기억 → 중복 없는 추천 / 대화형 상황 파악 / 네이버 지도 링크 즉시 연결
탐색 반경 능동 기준 도보 10분 이내 (약 800m)
2

기술 스택

항목 선택 비고
형태 HTML 단일 파일 서버 불필요
AI 엔진 OpenAI GPT-4o Chat Completions API + Function Calling
지도 네이버 지도 Web Dynamic Map 지도 표시용
식당 검색 OpenAI 지식 기반 네이버 Local Search API 대체
저장소 브라우저 localStorage 서버 없이 식사 기록 유지
3

핵심 기능

💬
AI 대화 추천

채팅 UI로 AI와 대화하며 추천받음. AI가 먼저 시간대·예산·인원·기피 음식을 자연스럽게 질문해서 파악.

🧠
식사 기억

최근 3일간 먹은 음식을 기억해 자동으로 중복 추천 회피. localStorage에 저장되어 앱 재시작 후에도 유지.

📍
네이버 지도 연결

추천된 가게를 클릭 한 번으로 네이버 지도 검색 페이지로 바로 이동.

🚫
중복 회피

오늘 포함 최근 3일치 식사 기록을 시스템 프롬프트에 자동 주입해 AI가 이미 먹은 음식을 피해 추천.

4

추천 결과 형식

항목 내용
가게 이름 추천 식당명
추천 메뉴 해당 가게의 대표 메뉴 1~2개
네이버 지도 링크 클릭 시 네이버 지도 검색 결과로 바로 이동
5

Memory (대화 기억)

항목 내용
저장 위치 브라우저 localStorage
보존 기간 최근 3일치 식사 기록 (오래된 것 자동 삭제)
저장 시점 사용자가 "먹었다" 확정 시 또는 AI가 save_meal 호출 시
저장 내용 날짜, 식사 시간대, 가게 이름, 메뉴
활용 방식 매 대화 시작 시 시스템 프롬프트에 자동 주입 → AI가 중복 추천 회피
6

Tools (AI Function Calling)

Tool 이름 설명 입력 출력
get_recent_meals localStorage에서 최근 3일 식사 기록 조회 없음 [{date, meal_time, place, menu}]
save_meal 식사 기록을 localStorage에 저장 {date, meal_time, place, menu} 저장 성공 여부
generate_naver_map_link 가게 이름으로 네이버 지도 검색 URL 생성 {place_name} 네이버 지도 검색 URL
get_current_datetime 현재 날짜 / 시간 / 요일 조회 없음 {date, time, weekday}
7

시스템 프롬프트 (초안)

# 역할 너는 광진구 능동에 사는 자취생의 식사 메뉴 추천 AI야. # 규칙 - 능동 기준 도보 10분 이내 (약 800m) 식당만 추천해 - 최근 3일간 먹은 음식은 반드시 피해 (기억 참고) - 추천 전에 아래 항목을 자연스럽게 대화로 파악해: → 식사 시간대 (아침/점심/저녁) → 예산 → 인원 (혼밥/같이) → 기피 음식 # 추천 형식 각 추천마다 반드시 포함: 1. 가게 이름 2. 추천 메뉴 3. 네이버 지도 링크 (generate_naver_map_link 도구 사용) # 식사 확정 시 사용자가 먹기로 결정하면 save_meal 도구로 기록 저장
8

API 키 현황

키 상태 비고
OpenAI API Key 확보 openai_key.env
네이버 Maps Key 확보 Web Dynamic Map
